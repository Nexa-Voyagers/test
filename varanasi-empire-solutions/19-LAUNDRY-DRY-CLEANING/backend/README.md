# LAUNDRY DRY CLEANING - Backend API

Production-ready backend API for LAUNDRY DRY CLEANING management system.

## Features

Complete REST API with CRUD operations for all modules, authentication, authorization, reporting, and analytics.

## Technology Stack

Node.js 20+ | Express.js | PostgreSQL 14+ | JWT | Swagger | Winston

## Installation

```bash
cd /home/user/test/varanasi-empire-solutions/19-LAUNDRY-DRY-CLEANING/backend
npm install
cp .env.example .env
npm run dev
```

## API Documentation

http://localhost:5019/api-docs

## Architecture

MVC + Service + Repository pattern with proper error handling, validation, security, and logging.
