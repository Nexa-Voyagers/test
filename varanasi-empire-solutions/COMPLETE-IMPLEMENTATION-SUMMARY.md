## ⚡ QUICK START GUIDE

### Deploy Restaurant POS (Fastest):
```bash
# 1. Start backend
cd 03-RESTAURANT-POS-MANAGEMENT/backend
npm install
cp .env.example .env
# Configure .env with database credentials
npm run dev
# Backend: http://localhost:5000

# 2. Start frontend
cd ../frontend
npm install
cp .env.example .env.local
# Configure NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1
npm run dev
# Frontend: http://localhost:3000

# 3. Load database
psql restaurant_pos_db < database/complete-schema.sql
psql restaurant_pos_db < ../shared/database/demo-data-generator.sql
psql restaurant_pos_db < database/demo-data.sql

# 4. Access application
# Frontend: http://localhost:3000
# API Docs: http://localhost:5000/api-docs
```

### Deploy Any Other Solution:
```bash
# Copy frontend starter
cp -r shared/frontend-starter/ [solution]/frontend

# Customize pages for your business
# Update API endpoints
# Deploy!
```
